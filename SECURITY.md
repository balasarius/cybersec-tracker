# Security Policy

## Supported versions

The project is pre-release. Security fixes currently target the latest commit on `main`. Supported release lines will be listed here before the first stable release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** private advisory form for this repository. If that facility is unavailable, contact the repository owner privately through GitHub and request a secure reporting channel without including exploit details in the first message.

Include affected versions, impact, reproduction steps, and any proposed mitigation. Remove real credentials, personal data, and production vulnerability information.

The maintainers aim to acknowledge reports within five working days, provide an initial assessment within ten working days, and coordinate remediation and disclosure with the reporter. Timelines may change with severity and complexity. Good-faith research that avoids privacy violations, service disruption, persistence, and data exfiltration is welcome.
