# Code of Conduct

## Our standard

We are committed to a respectful, inclusive, harassment-free project. Be considerate, discuss ideas rather than people, accept constructive feedback, and protect confidential security information.

Unacceptable behaviour includes harassment, discrimination, threats, doxxing, sustained disruption, sexualised conduct, or publishing another person's private information.

## Enforcement

Report conduct concerns privately to the project maintainers using the contact method in the repository's GitHub security settings. Maintainers may remove content, restrict participation, or ban contributors when behaviour threatens the community. Reports will be handled as confidentially as practical, with conflicts of interest disclosed and avoided.

This policy applies in project spaces and when representing the project elsewhere. It is adapted from the Contributor Covenant 2.1 principles; the project may adopt the full upstream text as governance matures.
